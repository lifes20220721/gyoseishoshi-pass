# 行政書士PASS

行政書士試験向けの、スマートフォン対応・静的学習サイトです。教材と問題は独自作成で、一般財団法人行政書士試験研究センターの過去問本文は収録していません。

## 収録機能

- 公式試験範囲に沿った6科目・20講義（行政法7講義）の科目別テキスト
- 行政法7分野の比較図・手続フロー図
- 2021〜2025年度の公式問題300問を分野別に集計し、頻出分野を補強
- 独自問題（○×97問、5肢択一22問、多肢選択式7問、40字記述式13問）
- 間違い問題の復習、科目別成績
- ブラウザ内の学習履歴保存と続きから再開
- 前の問題、関連テキストへの移動
- e-Gov法令検索への原文リンク
- PWA（ホーム画面への追加・オフラインキャッシュ）
- JSON形式の学習履歴バックアップ・復元

## ローカル確認

Service Workerを含むため、ファイルを直接開かずHTTPサーバーで確認します。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開いてください。

## GitHub Pages

ビルド工程はありません。リポジトリのルートをPagesの公開元に設定すると、そのまま配信できます。

## 教材の扱い

- 教材基準日：2026年4月1日
- 現行法確認日：2026年11月6日
- 受験時は対象年度の公式試験案内と最新法令を必ず確認してください。
- 公式過去問は、研究センターの「過去の試験問題と正解」ページへのリンクのみを掲載しています。
- 分野別集計は `official-topic-audit-v0.3.0.json`、傾向補強問題は `reinforcement-v0.3.0.js` に収録しています。

## 試験科目

- 法令等（46題）：憲法、行政法、民法、商法・会社法、基礎法学
- 基礎知識（14題）：一般知識、行政書士法等、情報通信・個人情報保護、文章理解
- 行政法は、一般法理論、行政手続法、行政不服審査法、行政事件訴訟法、国家賠償法、地方自治法を扱います。
