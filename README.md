# 行政書士PASS

行政書士試験向けの、スマートフォン対応・静的学習サイトです。教材と問題は独自作成で、一般財団法人行政書士試験研究センターの過去問本文は収録していません。

公開URL：<https://gyoseishoshipass.com/>

## 収録機能

- 公式試験範囲に沿った6科目・20講義（行政法7講義）の科目別テキスト
- 行政法7分野の比較図・手続フロー図
- 全1000問（行政法396問）を収録し、行政法は予測重要度順に演習
- 重要度は直近5年の分野配分等から算定した学習優先度で、将来の出題を保証するものではありません
- 2021〜2025年度の公式問題300問を分野別に集計し、頻出分野を補強
- 独自問題（○×341問、5肢択一506問、多肢選択式48問、40字記述式105問）
- 間違い問題の復習、科目別成績
- ブラウザ内の学習履歴保存と続きから再開
- 6科目それぞれの問題位置を自動保存し、科目選択後に続きから再開
- 前の問題、関連テキストへの移動
- e-Gov法令検索への原文リンク
- PWA（iPhone・Androidのホーム画面追加、standalone表示、オフラインキャッシュ、接続状態表示）
- JSON形式の学習履歴バックアップ・復元
- 検索エンジン向けcanonical・構造化データ・サイトマップ
- プライバシーポリシー、利用規約、運営情報、教材出典
- AdSense設定ファイルと広告同意管理（広告ID未設定時は外部通信なし）

## ローカル確認

Service Workerを含むため、ファイルを直接開かずHTTPサーバーで確認します。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開いてください。

## GitHub Pages

ビルド工程はありません。リポジトリのルートをPagesの公開元に設定すると、そのまま配信できます。

## 収益化設定

広告審査通過後に `monetization-config.js` へ本人のAdSenseクライアントIDと広告枠IDを設定し、`enabled` を `true` にします。未設定時は広告枠を表示せず、広告配信事業者への通信も行いません。canonical、サイトマップ、各ポリシーページは独自ドメイン `gyoseishoshipass.com` に設定済みです。

独自ドメイン、AdSense、`ads.txt` の設定順序は `MONETIZATION.md` を参照してください。

## 教材の扱い

- 教材基準日：2026年4月1日
- 現行法確認日：2026年11月6日
- 受験時は対象年度の公式試験案内と最新法令を必ず確認してください。
- 公式過去問は、研究センターの「過去の試験問題と正解」ページへのリンクのみを掲載しています。
- 分野別集計は `official-topic-audit-v0.3.0.json`、傾向補強問題は `reinforcement-v0.3.0.js` に収録しています。

## 試験科目

- 法令等（46題）：憲法、行政法、民法、商法・会社法、基礎法学
- 基礎知識（14題）：一般知識、行政書士法等、情報通信・個人情報保護、文章理解
- 行政法は、一般法理論、行政手続法、行政不服審査法、行政事件訴訟法、国家賠償法、地方自治法を扱います。
